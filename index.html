How

执行机制与兜底

学习方式

  • AI 当主讲 + 免费教程补充。不懂就追问到懂，让 agent 反过来教你 agent——贴合主线，零成本。

GitHub

  • 当成品仓库 + 学习档案。每一步产出都提交——既是过关证据，也是作品集。对专科尤其重要：这是“学历替代品”。

卡壳兜底（零基础最容易断在这里）

  1. 换 AI / 换问法：一个讲不明白就换另一个，或换个角度问
  2. 搜索验证：关键结论用官方文档交叉验证（AI 会幻觉，新手判断不了对错）
  3. 先跳过：卡住超过 2 小时就往下走，很多疑问后面自然懂
  4. 缩小问题：把报错拆到最小可复现的例子再问
  5. 回到产出：忘了为什么学就看一遍过关产出，只做通向它的事

预算

  • 免费额度先用满，真遇到瓶颈再投，别一开始就花钱。
