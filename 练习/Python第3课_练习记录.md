## 一、while 是干什么的

| # | 题目 | 我的答案 | 判定 |
|---|---|---|---|
| 1 | `n=1`；`while n<4: print(n); n=n+1` 打印什么？ | `1 2 3` | ✅ |
| 2 | `n=3`；`while n>0: print(n)` 有什么问题？ | 没有让条件变化，n 永远等于 3，死循环 | ✅ |
| 3 | 用 while 打印 `5 4 3 2 1` | `n=5` + `while n>0:` + 缩进 `print(n)` 和 `n=n-1` | ✅ |

## 要点

- for = 数着次数循环（已知跑几次，用 `range`）
- while = 满足条件就一直循环（不知道几次，只知道何时停）
- **while 必须有让条件最终变假的操作**（如 `n=n-1`），否则死循环
- 写 while 先自问："这循环靠什么停下来？"

## 二、列表

| # | 题目 | 我的答案 | 判定 |
|---|---|---|---|
| 1 | `fruits=["苹果","香蕉","橘子"]`，`print(fruits[1])` 和 `print(len(fruits))` | `香蕉` / `3` | ✅ |
| 2 | 把"橘子"加到末尾；把"苹果"改成"葡萄" | `fruits.append("橘子")` + `fruits[0]=("葡萄")`，实测 `['葡萄','香蕉','橘子']` | ✅ |
| 3 | `print(fruits[3])` 为什么报错？ | 只有下标 0 1 2，没有 3 | ✅ |

### 要点

- 列表 = 一排格子，下标从 **0** 开始
- `列表.append(东西)`：末尾加一个（`对象.方法` 的点读作"的"，必须指名对谁操作）
- `len(列表)`：元素个数
- `列表[下标] = 新值`：改某个元素
- 下标最大到 `len-1`，越界报 `IndexError`
- 小细节：`fruits[0]=("葡萄")` 的括号多余但能跑，`("葡萄")` 就是 `"葡萄"`；写 `fruits[0]="葡萄"` 更干净

### 答疑穿插

- `cups.append(...)` 的 `cups.` 是什么：append 是列表自带的方法，点号="的"，不写 `cups.` 就不知道往哪个列表加；对比 `print()` 是独立函数不用"谁."
- `append` = 在列表末尾添加一个元素

### 要点（函数）

- `def` = define，造函数；括号里是参数（空位），调用时"填进去"
- 参数 = 空位：定义时留空，调用时塞具体值；`计价(3)` 的 3 就是填进"杯数"
- 嵌套调用：`计价(int(input(...)))` 由内向外算（用户自己想到，理解到位）
- **`print` = 喊出来看，`return` = 交回给调用者**；没有 return 返回 None；想 `结果=函数()` 接住值必须 return
- `结果 = 函数()` 先算右边（触发调用）再存左边
- 定义了几个参数就必须传几个，少了报 `TypeError: missing required positional argument`
- 每个分支都能直接给结果时，不用中转变量 x，直接 `return`；函数内不 print、只 return，显示交给调用方

## ✅ 已填实的坑：print vs return（曾错 3 次，11-25 亲手实验攻克）

曾错 3 次：题2 加法缺 return；最大值相等分支 `x = print("一样大")` 返回 None；专项题1 `a = 计算(3)` 以为 `a=30`。

**根因**：把"print 显示出来"当成"函数把结果交出来"。

**11-25 对比实验（用户亲手跑，两张截图为证）**：

版本A（函数内 `print(y)`，无 return）→ 输出 `30` / `None`：

```python
def 计算(x):
    y = x * 10
    print(y)
a = 计算(3)
print(a)
```

版本B（保留 `print(y)`，加 `return y`）→ 输出 `30` / `30`：

```python
def 计算(x):
    y = x * 10
    print(y)
    return y
a = 计算(3)
print(a)
```

两行 30 的来源不同：第一行是函数内 `print(y)` 当场打的；第二行是 `return y` 把 30 交给 `a`，`print(a)` 再打的。

**用户自己的结论**：「不用 return 的话下面的 print 会显示 None，用上 return 时下面才会显示结果」——完全正确，坑填实。

## 已填实的坑：int vs str 方向

### 六步读写追加实验（先预测后跑，预测全中）

`练习/test_rw.py`：w 写第一句 → r 读 → w 写第二句 → r 读 → a 写第三句 → r 读。
预测：第4步"第二句"（第一句被覆盖）、第6步"第二句第三句"（追加）。
实测输出 `第一句 / 第二句 / 第二句第三句`，与预测一字不差。用户亲手改过 3 个报错后跑通。

### 要点（文件读写）

- `open(路径, 模式, encoding="utf-8")`：`r` 读 / `w` 写（覆盖）/ `a` 追加
- 一次 open 只能干一件事：写完要读回来，得重新 `open(..., "r")`
- `f.read()` 把内容**取出来**存变量，不显示；要 `print()` 才看得见（呼应 print/return 坑）
- `f.read()` 括号里不填路径（路径只在 open 里出现）；可填数字读前 N 字符
- `with open(...) as f:` 自动关闭文件，不用手写 `close()`；`as f` = 把文件对象命名为 f
- 写文件路径**用正斜杠 `/` 最安全**

### 已填实的坑（11-25，用户亲手改过）

1. **`\t` 转义坑**：路径 `"...\text.txt"` 里 `\t` 被当成 Tab 字符 → `OSError: [Errno 22] Invalid argument`。修法：路径全改正斜杠 `/`（或双反斜杠 `\\`、或前面加 `r`）
2. **少逗号坑**：`"w" encoding="utf-8"` 漏逗号 → Python 连成 `wencoding` → `TypeError: 'wencoding' is an invalid keyword argument`。修法：`"...", "w", encoding=...` 逗号隔开
3. **`wencoding` 手滑**：改逗号时模式处多敲个 `w`。修法：`encoding` 拼写检查

| # | 题目 | 我的答案 | 判定 |
|---|---|---|---|
| 1 | 建 `cat={"name":"咪咪","age":3}` 并打印咪咪 | 起初写 `cat{"咪咪",3}`（缺等号、花括号里是集合不是字典），纠正后 `print(cat["name"])` 输出咪咪 | ✅ |
| 2 | 改 age=4、加 color=橘色、删 name | `cat["age"]=4` / `cat["color"]="橘色"` / `del cat["name"]`，输出 `{'age':4,'color':'橘色'}` | ✅ 一次过 |
| 3 | `for key in d: print(key,d[key])` 输出 | "a 1 / b 2" 方向对；追问 print 逗号隔开的含义 | ✅ |
| 4 | 从 `order={"coffee":{"items":[...]}}` 取"拿铁" | 三层路径对，引号嵌套写错 `["coffee["items[1]"]"]`，纠正为 `["coffee"]["items"][1]` 输出拿铁 | ✅ |

### 要点（字典）

- 字典 = 带标签的格子，`{"键": 值}` 成对存；键加引号，值看类型
- 列表用数字下标 `fruits[1]`，字典用键名 `cat["name"]`——同一对 `[]`，列表填数字、字典填键
- 增删改查：`字典["键"]` 查（不存在报 KeyError，可用 `.get()`）；`字典["键"]=值` 键存在则改、不存在则增；`del 字典["键"]` 删
- 遍历：`for key in d: print(key, d[key])`；print 多参数用逗号分隔、自动空格连接
- 字典可嵌套（值是字典/列表）= API 返回数据的结构；取值口诀"看 `{` 用 `["键"]`，看 `[` 用 `[数字]`"，一节节往后接 `data["choices"][0]["message"]["content"]`
- 字典（内存数据结构）与 JSON（文本格式）：`json.dump` 写出、`json.load` 读回
- 三种括号分工：`()` 调用函数、`[]` 取值、`{}` 造字典

### 概念追问（用户高频问，均解答）

- `person`/`fruits`/`d` 是变量名可随意改（d=dict 首字母简称），关键字（if/for/dict/print）才不能当变量名
- `key` 是循环变量可改名，每轮拿到一个键，跟 `i` 是同一套路
- `[]` 是通用"取值"动作，"开柜子拿指定那一个"
- `d[key]` 输出 `1`（int，柜子里装的值）而非 "d1"；要文字 "d1" 得写 `"d"+str(d[key])`（字符串拼接）
- 变量赋值必须等号（`cat{...}` 报错）；`{"咪咪",3}` 是集合不是字典
